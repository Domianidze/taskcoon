# Taskcoon

Taskcoon is a warm, mascot-led todo app built with Expo and React Native. It focuses on a small set of everyday task actions and makes them feel smooth, tactile, and easy to return to.

## Feature Set

- Separately saved task lists for each username.
- Add, complete, delete, and reorder tasks.
- Detail editing for task descriptions.
- Responsive keyboard-aware layouts.
- Subtle haptics and animated transitions.

## Design Direction

I prioritized the feel of the app over feature density, aiming for a clean interface that stays focused on the core todo actions. The layout intentionally adapts when the keyboard opens: key elements shift, collapse, or re-center so the UI feels responsive instead of cramped.

Animations are subtle and supportive, not decorative; transitions fade, lift, and resize gently to guide attention without slowing interaction. I also added light haptic feedback for key actions like adding, completing, reordering, saving, and deleting tasks to make interactions feel more tactile and satisfying. The mascot-driven experience keeps the app warm and memorable, using progress states and friendly copy to encourage users to come back and keep completing tasks.

## How to Install

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```

From the Expo terminal, press `i` to open iOS, press `a` to open Android, or scan the QR code with your phone to open it in Expo Go.
